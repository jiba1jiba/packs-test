Установка

Три шага
до первого пака

Скачайте архив с проектом плагина: внутри исходный код и ваш конфиг из конструктора. Одна команда сборки — и .jar готов.

Быстрый старт
01

Скачайте и соберите плагин

В архиве — проект с исходным кодом и вашим config.yml. Нужны JDK 21+ и Maven: выполните mvn package в папке проекта, положите target/PurpurPacks-1.0.0.jar в plugins/ и перезапустите сервер.

server / plugins
plugins/
└─ PurpurPacks/
   ├─ config.yml
   └─ data.yml
02

Настройте паки

Соберите конфиг в конструкторе выше и скачайте config.yml. Либо отредактируйте файл вручную — все ключи понятны.

config.yml
packs:
  amethyst:
    display-name: "<light_purple>Аметистовый пак</light_purple>"
    container: SHULKER
    color: PURPLE
03

Выдайте и откройте

При установке контейнер открывается, игрок подпрыгивает. После цветных панелей появляются 10-15 наград, по одной в секунду. Анимация идёт с пропуском 2-4 позиций и продолжает круг со свободных слотов.

console / chat
# применить конфиг без рестарта
/packs reload
# выдать первый пак игроку
/packs give amethyst Steve

FAQ

Коротко
о главном

Не нашли ответ? Конфиг открыт, комментарии внутри — а всё остальное настраивается за пару минут.

Инструкция по установке
Как добавить новый пак?

Добавьте секцию в packs внутри config.yml — или соберите пак в конфигураторе и скачайте готовый файл. Укажите уникальный ID, название, контейнер и список лута. После этого выполните /packs reload.

Можно ли сделать из шалкера сундук?

Да. В настройках пака переключите container: SHULKER на CHEST. Лут, название, цвет, частицы, звук и формат сообщения не изменятся. Материал контейнера пересчитается автоматически.

Что именно пишется в чат?

Формат messages.open поддерживает плейсхолдеры {player}, {number}, {pack}, {total} и MiniMessage-разметку: цвета, градиенты, жирный текст. По умолчанию в чат уходит что-то вроде «Steve открывает 1-й Аметистовый пак».

Где хранятся счётчики открытий?

В data.yml, чтобы обновление конфига не обнуляло статистику. Режим count-mode позволяет вести общий счётчик пака или персональный для каждого игрока. Сбросить значения можно командой /packs reset.

Нужен ли перезапуск сервера?

Нет. После редактирования конфига выполните /packs reload. Плагин перечитает паки и сообщения на лету; игрокам ничего перезаходить не нужно.

Совместим ли с PlaceholderAPI?

Да, если на сервере стоит PlaceholderAPI, в сообщениях можно использовать его плейсхолдеры. Плагин работает на Paper API и собирается под Java 21+.
